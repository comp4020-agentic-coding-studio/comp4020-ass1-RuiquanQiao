# Assignment 1

## The breakthrough

It took five topics to get here; I threw the first four away for the same reason
each time — I couldn't work out what I'd be *entitled to say*. An extinction
simulator needed a causal chain no paper provides; a time-slider over ancient
coastlines needed images of places nobody photographed. I kept treating that as
bad luck. The breakthrough was seeing it wasn't luck but a preference, and that I
should choose a project that *ran on* it rather than one that survived it. Who
taught whom is recorded. That is why this topic worked when better-looking ideas
didn't.

Then the harness gave the preference teeth. Before any data existed I wrote a
rule that a person's name may never be a bare QID. It read like housekeeping. It
caught a television character listed as a physics laureate, a *family* entity
recorded as a person, and — the one that frightened me — Niels Bohr rendered as
`Q7085`, because Wikidata had moved names like his to a language code I wasn't
asking for.

## What it changed

I used to write tests against bugs I'd already found, which only ever catches
that bug again. Now I want to write them against what must be *true of the
output*: a contrast check I added for a new light theme failed immediately on
the dark one, live since the first commit.

The harder change is a habit I didn't know I had. Twice in one week I answered a
visual defect by making it invisible — painting over crossing lines, then bending
them to lie about the shape they described. What broke the pattern was building
the measurement before the next attempt: once I could count crossings, the fix
stopped being a matter of taste. I want that to be the order I work in — measure,
then decide — because I now know what I do when I skip it.
